# Version 0.2.0

This version provides nine publication figures, thirteen bundled plot-source CSVs, fourteen supplementary source tables, the restricted-input analysis scripts and portable staging interface, the paired patient-cluster bootstrap and boundary-interval definitions, and P3 rule concordance reported separately from the clinical comparison. The dependency lock and asset manifests describe the file set in this package.

The synthetic rule implementations are demonstrations. The publication layout is retained, with an explicit installed-font fallback for portable rebuilding.
