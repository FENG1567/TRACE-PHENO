## 6. 推荐上传方式

在本文件夹根目录初始化 Git 仓库并提交全部未被 `.gitignore` 排除的文件。不要手动把 `artifacts/`、任何受限数据目录或 `.env` 强制加入提交。

上传前可再次运行：

```powershell
py -3.12 scripts/reproduce_public.py
py -3.12 scripts/verify_checksums.py
```

若第二条命令提示校验和不一致，说明自上次清单生成后文件发生变化，应先审查变化，再运行 `py -3.12 scripts/build_public_manifest.py` 重新冻结清单。
