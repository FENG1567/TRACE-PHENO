# Scope of the examples and results

The empirical AP comparison uses a clinician-adjudicated reference set. P0–P2 conditional agreement is exploratory; P3 shares reference decision rules and is reported as rule concordance. P4 equivalence concerns complete binary three-domain inputs. P5 remains a specification because the development sample contains 39 adjudicable positives.

Cross-database results describe available evidence and operational cohort selection. The downstream mortality contrasts describe overlapping selected cohorts. The AKI example and the public AP parser are synthetic demonstrations. Restricted source records and the original frozen project are needed for clinical numerical reproduction.
