# Reproducibility and evidence limitations

- The reference set reflects blinded, independent adjudication by two experienced surgical clinicians, with a third surgical clinician resolving disagreements; labels may still contain semantic errors.
- Conditional agreement estimates are exploratory and precision limited.
- P3 shares evidence rules with the reference construction; high agreement is rule-concordance.
- P4 is logically equivalent to P3 on complete binary three-domain inputs.
- The public aggregate package cannot recreate patient-clustered bootstrap intervals without restricted row-level inputs.
- Early-window AP identification was not estimable because most sampled records lacked sufficient early evidence.
- Cross-database outputs characterize transportability and coverage.
- Hospital-level identifiers and hospital-level numerator/denominator rows were removed from the public package.
- The AKI example is synthetic and demonstrates schema reuse only.
