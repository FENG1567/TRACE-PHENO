# Data availability

The package includes source code, specifications, synthetic examples, aggregate analysis tables and figure source data. MIMIC-IV, eICU-CRD, NWICU, SICdb and HiRID must be obtained through their providers under the relevant access and data-use terms. No patient-level source records, narratives, review packets or identifier mappings are distributed here.

The versions used are recorded in `configs/database_releases.json`: MIMIC-IV 3.1 with Note 2.2, eICU-CRD 2.0, NWICU 0.1.0, SICdb 1.0.8 and HiRID 1.1.1. Listed source periods are those reported by the providers.
